# Как обновить сайт на GitHub Pages

## Способ 1: Автоматическое обновление (РЕКОМЕНДУЕТСЯ)

### Если используете "Deploy from a branch":

1. **Внесите изменения в файлы** (index.html, styles.css, script.js)
2. **Закоммитьте и запушьте изменения:**
   ```bash
   git add .
   git commit -m "Обновление сайта"
   git push
   ```
3. **Подождите 1-2 минуты** - GitHub автоматически обновит сайт

### Если используете GitHub Actions:

1. **Внесите изменения в файлы**
2. **Закоммитьте и запушьте:**
   ```bash
   git add .
   git commit -m "Обновление сайта"
   git push
   ```
3. **Проверьте Actions:**
   - Перейдите в репозиторий → вкладка **Actions**
   - Дождитесь завершения workflow "Deploy to GitHub Pages"
   - Сайт обновится автоматически

---

## Способ 2: Через веб-интерфейс GitHub

1. **Откройте файлы на GitHub:**
   - Перейдите в репозиторий
   - Откройте нужный файл (например, `index.html`)

2. **Нажмите на иконку карандаша** (Edit this file)

3. **Внесите изменения**

4. **Прокрутите вниз** и нажмите **"Commit changes"**

5. **Подождите 1-2 минуты** - сайт обновится автоматически

---

## Способ 3: Принудительное обновление через Actions

Если сайт не обновляется автоматически:

1. **Перейдите в репозиторий → Actions**

2. **Найдите workflow "Deploy to GitHub Pages"**

3. **Нажмите "Run workflow"** (кнопка справа)

4. **Выберите ветку** (обычно `main`)

5. **Нажмите "Run workflow"**

6. **Дождитесь завершения** - сайт обновится

---

## Способ 4: Пересборка через Settings

1. **Перейдите в Settings → Pages**

2. **Измените настройки:**
   - Измените Branch на другую, затем верните обратно
   - Или измените Folder и верните обратно

3. **Нажмите Save**

4. **Подождите** - GitHub пересоберет сайт

---

## Проверка обновления

1. **Очистите кэш браузера:**
   - Нажмите `Ctrl + Shift + R` (Windows) или `Cmd + Shift + R` (Mac)
   - Или откройте сайт в режиме инкогнито

2. **Проверьте версию:**
   - Откройте сайт
   - Нажмите `F12` (DevTools)
   - Перейдите на вкладку Network
   - Обновите страницу (`F5`)
   - Проверьте, что файлы загружаются заново

---

## Время обновления

- **Обычно:** 1-2 минуты после push
- **Максимум:** до 10 минут для первого развертывания
- **Если долго:** проверьте Actions на наличие ошибок

---

## Частые проблемы

### Сайт не обновляется:

1. **Проверьте коммиты:**
   - Убедитесь, что изменения закоммичены
   - Проверьте, что они запушены в правильную ветку

2. **Проверьте Actions:**
   - Перейдите в Actions
   - Убедитесь, что нет ошибок в workflow

3. **Очистите кэш:**
   - Браузер может показывать старую версию
   - Используйте `Ctrl + Shift + R` для жесткой перезагрузки

4. **Проверьте настройки Pages:**
   - Settings → Pages
   - Убедитесь, что выбран правильный источник

---

## Быстрая команда для обновления

Если у вас настроен Git, просто выполните:

```bash
cd "путь/к/репозиторию/docs"
git add .
git commit -m "Обновление сайта"
git push
```

Сайт обновится автоматически через 1-2 минуты!
