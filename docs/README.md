# NEVERWENZ Website

Официальный сайт для Roblox Injector - NEVERWENZ

## Размещение на GitHub Pages

1. Создайте репозиторий на GitHub (например, `CAPYBERA099/neverwenz-website`)
2. Загрузите все файлы из папки `docs` в корень репозитория
3. Перейдите в Settings → Pages
4. В разделе "Source" выберите "Deploy from a branch"
5. Выберите ветку `main` и папку `/ (root)`
6. Нажмите Save
7. Сайт будет доступен по адресу: `https://CAPYBERA099.github.io/neverwenz-website/`

## Структура файлов

```
docs/
├── index.html      # Главная страница
├── styles.css      # Стили
├── script.js       # JavaScript
└── README.md       # Этот файл
```

## Настройка

Все ссылки на установщик уже настроены на:
- `https://raw.githubusercontent.com/CAPYBERA099/setup/main/RobloxInjectorSetup.exe`

Если нужно изменить ссылку, отредактируйте файл `index.html` в секции download.
