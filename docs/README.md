# Сайт игры Antonov - Beta 3.0

Современный веб-сайт для игры Antonov с возможностью скачивания бета-версии 3.0.

## Структура файлов

```
game_website/
├── index.html      # Главная HTML страница
├── style.css       # Стили и дизайн
├── script.js       # JavaScript функциональность
└── README.md       # Этот файл
```

## Как использовать

1. **Размещение файлов:**
   - Загрузите все файлы на ваш веб-сервер
   - Убедитесь, что файл `parasha_antonov2.apk` находится в корневой директории сайта
   - Или обновите ссылку в `index.html` на правильный путь к APK файлу

2. **Настройка:**
   - Откройте `index.html` в текстовом редакторе
   - Найдите строку с ссылкой на скачивание: `<a href="parasha_antonov2.apk" ...>`
   - Измените путь на ваш APK файл, если нужно

3. **Запуск:**
   - Откройте `index.html` в браузере
   - Или загрузите на веб-сервер и откройте через домен

## Настройка

### Изменение информации о версии

В файле `index.html` найдите и измените:
- Текст "BETA 3.0" на нужную версию
- Дату релиза (устанавливается автоматически через JavaScript)

### Изменение цветов

В файле `style.css` измените переменные в секции `:root`:
```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    --accent-color: #ec4899;
    /* и т.д. */
}
```

### Добавление скриншотов

Замените `<div class="image-placeholder">` в секции "О игре" на:
```html
<img src="path/to/screenshot.jpg" alt="Скриншот игры">
```
