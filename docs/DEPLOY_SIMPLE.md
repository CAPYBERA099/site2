# Быстрая инструкция: Размещение сайта на GitHub Pages

## Самый простой способ:

1. **Создайте новый репозиторий** на GitHub (например, `neverwenz-website`)

2. **Скопируйте эти 3 файла в корень репозитория:**
   - `index.html`
   - `styles.css`
   - `script.js`

3. **Настройте Pages:**
   - Settings → Pages
   - Source: **Deploy from a branch**
   - Branch: `main`, Folder: `/ (root)`
   - Save

4. **Готово!** Сайт будет по адресу:
   ```
   https://ваш-username.github.io/neverwenz-website/
   ```

## Или используйте текущий репозиторий:

1. Убедитесь, что файлы в папке `docs/` закоммичены
2. Settings → Pages
3. Source: **Deploy from a branch**
4. Branch: `main`, Folder: `/docs`
5. Save

Сайт: `https://CAPYBERA099.github.io/WenzInjector-ROBLOX/`
